# ACT.IN.ART.
## Indiana Art Activist Directory

**ACT.IN.ART.** (Activism Indiana Artistry) is a living, curated directory of Indiana-based activist artists, collectives, and artworks.

### Why it exists
**To inspire others to create change in Indiana through art** and to influence how we think about present-day issues by making activist art visible, contextualized, and easy to explore.

### What you’ll find
- Artist and project profiles with images, bios, media links, and cause context  
- An interactive map of activist art across Indiana  
- A timeline showing activism themes across decades  
- Analytics that reveal patterns and representation gaps  
- Curated collections that feel like mini digital exhibitions  

### New ways to engage
- **Search+** — faster, friendlier discovery  
- **Saved lists + sharing** — create your own recommendations  
- **Tours** — build a route of works you want to visit  
- **Zine Builder** — generate printable mini-publications  
- **Events** — connect the directory to real-world happenings  
- **Reflections** — share how a piece impacted you (moderated)

### The promise
ACT.IN.ART. is not a final list.  
It is a **living directory** that grows with the community.

### How you can help
- Suggest new entries  
- Submit corrections or better links  
- Share reflections  
- Recommend events  
- Request takedowns when needed

**Local art changes how local communities think.  
This directory exists to help that change travel farther.**
